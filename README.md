# 🐘 PHP Object-Oriented Programming (OOP)
Welcome to my PHP learning repository! This space is dedicated to collecting practical exercises, code challenges, and core OOP concepts (Classes, Objects, Inheritance, and Composition) that I develop as I progress through my training by ITAcademy.

## 🚀 Development Environment
- **PHP** (Version 8.2.12)
- **Editor:** Visual Studio Code
- **Recommended Extension:** PHP Server (or whichever extension you use to run them)

## 📂 Repository Structure
The project is organized by difficulty levels for easy navigation:

- **nivel1/** : Core OOP principles including basic class structures, methods, initialization, and class inheritance.
- **nivel2/** : (Empty - To be developed)
- **nivel3/** : (Empty - To be developed)

## 🛠️ How to Run This Project
If you want to test these exercises in your local environment using Visual Studio Code, follow these steps:

1. **Clone this repository:** `https://github.com/JoseBermejo-N/TascaS1.04.git`
2. **Open the folder in your editor:** Open Visual Studio Code, go to File -> Open Folder, and select the cloned repository folder.
3. **Run the files:**
   - Open any `.php` file.
   - Right-click inside the editor and select "Run code".
